# Saudi Digital Banking QA Framework:
_______________________________________________________
A complete Software Testing and Quality Assurance project for a Digital Banking Account Opening System.
_______________________________________________________
Project Overview:
This project simulates the testing activities performed by a Software Quality Engineer in the banking sector.
_______________________________________________________
The framework covers:
Functional Testing
API Testing
Automation Testing
SQL Validation
Defect Tracking
Test Planning
Test Reporting
CI/CD Integration
_________________________________________
Modules Under Test:
Login
Customer Registration
National ID Validation
OTP Verification
Account Opening
Dashboard
_______________________________________________________
Technologies:
Java
Selenium WebDriver
TestNG
Maven
Postman
SQL
GitHub Actions
